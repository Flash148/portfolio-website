## Overview

This project is a web application that analyzes uploaded images and extracts their dominant color palettes using the K-means clustering algorithm. Built with a Python/Flask backend and a clean, responsive frontend, it gives designers and developers isntant access to hex does and RGB values from any image. 

## Features

- K-means machine learning algorithm for accurate domninant color extraction
- Customizable output of 2-10 colors per image
- One-click hec code copying to clipboard
- Visual percentage display showing how much of each color appears in the image
- Responsive design that works across desktop, tablet, and mobile
- Clean modern UI with smooth animations
